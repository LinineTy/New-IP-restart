# Linux 脚本（检测IP变化以重启）

> 一个用于检测服务器当前获取到的 IP，并在其变化时重启服务器的 Shell 脚本

适用于动态 IP 的家庭网络环境，用于解决因分配 IP 变化但旧 IP 租期未过期导致的服务器无法连接 / 超时问题，通过自动重启服务器以重新获取上游所分配的 IP 地址
依赖 Linux Crontab 命令（定时执行），建议设定执行间隔为 5 分钟

## 使用方法：

1. 解压脚本到根目录下
2. 打开系统 crontab（crontab -e），添加 `*/5 * * * * /ipr/iprs.sh`
3. 进入到 ipbox 目录下
4. 授予 iprs.sh 权限（chmod +x iprs.sh ）

**注意要先按照 iprc.sh 内的提示修改相关配置**
